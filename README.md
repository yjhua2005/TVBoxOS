## 📖 项目简介

**白盒多仓版** 是一个开源的 TVBox 衍生版本，它保留了 TVBoxOS 的核心播放能力，同时：

- 🎨 **像素级复刻「影视仓」UI** – 界面美观，操作顺手，大屏体验优化。
- 📦 **原生支持多仓** – 内置多仓配置界面，轻松切换海量资源站。
- ☁️ **网盘 & 本地播放** – 支持 Alist、FTP、SMB、WebDAV 等，直接播放网盘视频。
- 🛠️ **持续维护** – 作者长期更新，修复问题，适配新接口。

你可以把它当作日常观影工具，也可以作为**二次开发的基础**——我们提供了完整的移植文档，方便你把多仓功能集成到自己的项目中。

---

## ✨ 主要特性

| 功能 | 说明 |

| **直播支持** | 内置直播源切换，可自定义 |

## 🚀 快速开始

### 1. 直接使用（推荐普通用户）

前往 [Releases](https://github.com/yjhua2005/TVBoxOS/releases) 页面，下载最新的 APK 安装包，直接安装到你的电视盒子上即可。

> 首次打开后，请在「设置」→「配置地址」中输入你的多仓地址（或本地文件），即可开始使用。

### 2. 自行编译（推荐开发者）

如果你有 Android 开发环境，可以克隆源码自行编译：

```bash
git clone https://github.com/yjhua2005/TVBoxOS.git
cd TVBoxOS
# 使用 Android Studio 打开项目，或者命令行编译
./gradlew assembleRelease
